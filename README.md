# MakeWeYarn

## Mobile Telecom Service Operations Platform

MakeWeYarn is a telecommunications-modeled application that simulates core operations of a fictional Nigerian mobile network operator.

### Project Objectives

- Manage fictional mobile subscribers.
- Maintain mobile data plans and subscriptions.
- Track simulated cellular network sites.
- Record and manage network incidents.
- Expose application health and monitoring metrics.
- Demonstrate containerization, orchestration, automation, and observability using DevOps tools.

### Planned Technology Stack

- Python and Flask
- PostgreSQL
- Docker and Docker Compose
- Kubernetes and Kustomize
- NGINX Ingress
- GitHub Actions
- Prometheus and Grafana

### Project Scope

This project is intended for learning and portfolio demonstration. Subscriber records and network activity will be simulated. It will not connect to a real telecommunications network or process real subscriber data.

### Project Status
